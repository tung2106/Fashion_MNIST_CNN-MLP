# Lệnh hỗ trợ

Chạy từ gốc dự án:

- `python -m scripts.xem_du_lieu`: xem ảnh/nhãn/pixel và số mẫu; không train.
- `python -m scripts.dong_goi_colab`: tạo `experiments/source.zip` cho Colab; không kèm data/checkpoint.

Các công cụ tạo bài học cũ giữ trong `archive/learning_scripts/`, không dùng để tạo đè notebook hiện tại.
