# Lệnh hỗ trợ

Chạy từ gốc dự án:

- `python -m scripts.inspect_data`: xem ảnh/nhãn/pixel và số mẫu; không train.
- `python -m scripts.pack_source`: tạo `experiments/source.zip` cho Colab; không kèm data/checkpoint.

Các công cụ tạo bài học cũ giữ trong `archive/learning_scripts/`, không dùng để tạo đè notebook hiện tại.
