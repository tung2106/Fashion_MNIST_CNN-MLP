# Tài liệu dự án

- `concepts/`: [khái niệm cơ bản dạng Word](concepts/khai_niem_co_ban.docx).
- `guides/code/`: [cách đọc mã](guides/code/cach_doc_ma_nguon.md), [giao thức](guides/code/giao_thuc_chon_mo_hinh.md), [trạng thái thực nghiệm](guides/code/trang_thai_thuc_nghiem.md).

[Cấu trúc và quy tắc đường dẫn](project_structure.md) giải thích cách các phần kết nối. [Báo cáo nhóm hiện tại](../reports/README.md) nằm riêng ở reports.

Mã nguồn và báo cáo nhóm trước giữ riêng ngoài dự án tại `D:\Tham khảo nhóm trước`, không thuộc nội dung bàn giao của nhóm hiện tại.
